# EcomIQ – E-Commerce Sales, Customer & Product Analytics

## 📌 Project Overview

An end-to-end Power BI business intelligence project
analyzing e-commerce sales, customers, products,
orders, payments and customer retention.

## 🎯 Objectives

- Analyze sales performance
- Understand customer behaviour
- Identify top products and categories
- Analyze orders and payment methods
- Monitor customer retention
- Generate actionable business recommendations

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling

## 📊 Dashboard Pages

1. Sales Analysis
2. Customer Insights
3. Product Analysis
4. Orders & Payments
5. Customer Retention
6. Executive Summary

## 💡 Key Insights

- Total Revenue: ₹116.15M
- Total Orders: 500
- Repeat Customer Rate: 95%
- Delivery Rate: 69.80%
- Cancellation Rate: 10.60%

## 🎯 Recommendations

- Focus on high-performing categories
- Strengthen customer loyalty
- Reduce cancellations
- Improve delivery performance
- Monitor low-stock products
